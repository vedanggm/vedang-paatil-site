VEDANG PAATIL — PORTFOLIO SITE
==============================

HOW TO RUN
----------
You need Node.js installed (https://nodejs.org — any version 16+).

  1. Unzip this folder somewhere.
  2. Open a terminal in this folder.
  3. Run:   node server.js
  4. Open:  http://localhost:3000

That's it. No npm install, no build step, no internet needed.

Mac/Linux shortcuts:
  ./start.sh          (then open http://localhost:3000)
  PORT=8080 node server.js     to use a different port

Windows: double-click start.bat, or run  node server.js

WHY A SERVER AND NOT JUST OPENING index.html
--------------------------------------------
The site is a Next.js build. Its asset paths are absolute ("/_next/...",
  "/images/..."), which browsers cannot resolve from file://. Opening
  index.html directly will show an unstyled page. The bundled server.js
  resolves those paths and also handles the three dynamic routes the site
  needs:

  /_next/image?...   the image-optimizer endpoint (work thumbnails)
  Range requests     so <video> can stream and seek
  clean URLs         /library, /cgv, /prompts/... resolve to .html files
